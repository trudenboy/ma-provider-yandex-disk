Провайдер отдаёт Music Assistant содержимое выбранной папки Яндекс Диска
двумя способами: живой просмотр каталога (Browse) и полная синхронизация
библиотеки.

## Просмотр каталога (Browse)

Во вкладке Browse видна структура папок Диска начиная с корневой папки,
заданной в настройках (например, `disk:/Music`). Аудиофайлы можно
воспроизводить прямо из дерева, не дожидаясь синхронизации. Списки папок
кэшируются на 5 минут.

## Синхронизация библиотеки

Синхронизация обходит корневую папку целиком и наполняет библиотеку
Music Assistant треками, альбомами, исполнителями и плейлистами — метаданные
читаются из тегов самих файлов, как в обычном файловом провайдере.

- Изменения определяются по `md5` каждого файла: повторные синхронизации
  обрабатывают только новое и изменённое.
- Синхронизация всегда запрашивает свежие списки папок, минуя кэш.
- Тип контента экземпляра (музыка / аудиокниги / подкасты) определяет, как
  индексируются файлы.

## Несколько экземпляров

Провайдер поддерживает несколько экземпляров одновременно — например,
разные аккаунты Яндекса или разные папки одного Диска (музыка отдельно,
аудиокниги отдельно).
