Файлы воспроизводятся в исходном качестве — провайдер ничего не
перекодирует и отдаёт байты как есть (source quality).

## Как устроен стриминг

Плееры не ходят на Яндекс напрямую: поток идёт через собственный
прокси-маршрут Music Assistant. На каждое воспроизведение провайдер
запрашивает у API Диска свежую подписанную ссылку на скачивание, поэтому
истечение срока действия ссылок не прерывает работу.

## Перемотка (seek)

HTTP-заголовок `Range` от плеера пробрасывается до Яндекса без изменений,
так что перемотка не требует докачивать файл с начала — это заметно на
длинных аудиокнигах и DJ-сетах.
