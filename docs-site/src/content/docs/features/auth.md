Провайдер авторизуется через **ваше собственное** OAuth-приложение Яндекса
с единственным правом — чтение Диска (`cloud_api:disk.read`). Это та же
модель, что у встроенного провайдера Google Drive.

## Device Flow

После отправки формы Music Assistant покажет короткий код и ссылку для
подтверждения на Яндексе. Введите код и разрешите доступ — flow обнаружит
подтверждение и завершит настройку автоматически. Истёкший код заменяется на
новый прямо на этой странице. Ручного поля `auth_code` и отдельного статуса для
сохранения больше нет.

## Обновление токена

Access-токен обновляется автоматически по refresh-токену. Если Яндекс выдаёт
новый refresh-токен, он сразу сохраняется в зашифрованных данных настройки.
Повторная авторизация нужна, только если отозвать доступ приложению или удалить
само приложение.

## Только чтение

Скоуп даёт доступ исключительно на чтение — провайдер физически не может
изменить или удалить что-либо на вашем Диске.

Пошаговая инструкция по регистрации приложения — на странице
