## Добавление Yandex Disk в Music Assistant

1. Откройте **Music Assistant → Настройки → Источники музыки**.
2. Нажмите **«+ Добавить»** и выберите **Yandex Disk**.
3. Следуйте инструкциям на экране для настройки провайдера.

## Параметры подключения

| Параметр | Значение |
|:---------|:---------|
| **Сервис** | [https://360.yandex.ru/disk/](https://360.yandex.ru/disk/) |
| **Метод аутентификации** | OAuth своё приложение Яндекс (код подтверждения, cloud_api:disk.read, авто-refresh) |
| **Макс. качество звука** | Source quality (файлы как есть) |

Подробное описание всех параметров смотрите в диалоге настройки провайдера в Music Assistant.
