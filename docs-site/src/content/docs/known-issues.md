## Нужно собственное OAuth-приложение Яндекса

**Симптомы:** провайдер нельзя подключить «в один клик» — форма требует
Client ID и Client Secret.

**Причина:** у Яндекса нет проверенного публичного first-party клиента,
выдающего токены для Диска, а WebDAV-доступ по паролю приложения требует
платной подписки Яндекс 360.

**Решение:** зарегистрируйте бесплатное приложение с правом
`cloud_api:disk.read` — по шагам это описано на странице
[Настройка](../configuration/). Делается один раз.

## Новые файлы появляются в браузере каталога с задержкой

**Симптомы:** файл только что загружен на Диск, но во вкладке Browse его
ещё не видно.

**Причина:** списки папок кэшируются на 5 минут, чтобы не дёргать API
Яндекса на каждый клик.

**Решение:** подождите до 5 минут или запустите синхронизацию библиотеки —
она всегда запрашивает свежие списки.

## Тип контента нельзя сменить после настройки

**Симптомы:** в настройках существующего экземпляра не меняется тип
контента (музыка / аудиокниги / подкасты).

**Причина:** тип контента определяет, как индексируется библиотека, и
задаётся только при первичной настройке.

**Решение:** добавьте отдельный экземпляр провайдера с нужным типом
контента (несколько экземпляров поддерживаются — например, один на
`disk:/Music`, другой на `disk:/Audiobooks`).

## Провайдер перестал работать после отзыва доступа

**Симптомы:** синхронизация и воспроизведение падают с ошибкой
авторизации.

**Причина:** refresh-токен стал недействительным — доступ приложению
отозван на странице [управления доступами Яндекса](https://id.yandex.ru/security)
либо само приложение удалено. Пока доступ не отозван, токен обновляется
автоматически и повторная авторизация не требуется.

**Решение:** повторите авторизацию в настройках провайдера через **Sign in
with Yandex** и введите новый Device Flow-код на странице Яндекса.

## Первая синхронизация большой библиотеки идёт долго

**Симптомы:** после добавления провайдера библиотека наполняется
постепенно, синхронизация занимает заметное время.

**Причина:** при первом проходе Music Assistant читает теги из самих
файлов, а для этого скачивает их фрагменты с Диска.

**Решение:** это разовая операция — дождитесь окончания первого прохода;
последующие синхронизации сверяют `md5` файлов и обрабатывают только
изменения.
